# Security policy

## Supported versions

Only the latest release line gets security fixes. Before 1.0 that is the newest `0.MINOR` tag: update with
`composer update yanfishel/atarcms-core`, `bin/atar migrate` and the steps in `UPGRADE.md`.

## Reporting a vulnerability

Please do not open a public issue for a vulnerability. Report it privately through GitHub's "Report a
vulnerability" at https://github.com/yanfishel/atarcms-core/security/advisories — include the affected version, how to
reproduce it and, if you can, the impact you see. You will get an answer within a week. A confirmed vulnerability
is fixed in the next release and credited to you in `CHANGELOG.md`, unless you prefer otherwise.
