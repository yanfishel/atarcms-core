# Security policy

A vulnerability in a site built from this skeleton is almost always a vulnerability in the AtarCMS core
(`yanfishel/atarcms-core`). Please do not open a public issue: report it privately through GitHub's "Report a
vulnerability" at https://github.com/yanfishel/atarcms-core/security/advisories. The core's `SECURITY.md` has the
supported versions and what to include.
