# Contributing

This repository is the AtarCMS site skeleton, exported from a private development repository with every release —
one commit per version. Pull requests cannot be merged into it directly.

- **Bug reports and feature requests:** open an issue here, or on the core at
  https://github.com/yanfishel/atarcms-core for the CMS itself.
- **Security problems:** never an issue — see `SECURITY.md`.
- **Patches:** open an issue describing the change first. An accepted change is applied in the development
  repository and ships with the next release, credited in the core's `CHANGELOG.md`.
