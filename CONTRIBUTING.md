# Contributing

AtarCMS is developed in a private repository; the public repository is a mirror that gets one commit per release,
so its history starts at the first public version and pull requests cannot be merged into it directly.

- **Bug reports and feature requests:** open an issue on https://github.com/yanfishel/atarcms-core.
- **Security problems:** never an issue — see `SECURITY.md`.
- **Patches:** open an issue describing the change first. An accepted change is applied in the development
  repository and ships with the next release, credited in `CHANGELOG.md`.
